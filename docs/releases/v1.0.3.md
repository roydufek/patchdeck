# Patchdeck v1.0.3

Release date: 2026-06-01

## Summary
Security maintenance release. Clears all known HIGH/CRITICAL CVEs in the Go backend by updating the Go toolchain and dependencies. Trivy image scan (HIGH,CRITICAL): **17 → 0**.

## Security
- Bumped Go toolchain **1.22 → 1.25** (build stage + `go` directive), clearing 14 Go stdlib HIGH/CRITICAL advisories — including CVE-2025-68121 (crypto/tls incorrect certificate validation during TLS session resumption, the lone CRITICAL).
- Updated `golang.org/x/crypto` v0.32.0 → v0.52.0 (CVE-2025-22869: SSH key-exchange DoS).
- Updated `github.com/golang-jwt/jwt/v5` v5.2.1 → v5.3.1 (CVE-2025-30204: excessive memory allocation during header parsing).

## Fixed
- Default reported version corrected from `0.1.0-alpha` to track the release line (was stale in config defaults, so the running container mis-reported its version).

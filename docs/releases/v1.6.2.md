# Patchdeck v1.6.2

Release date: 2026-06-02

## Summary
Simplified the per-host connection indicator to a clear three-state dot and replaced the amber "glow ring" (which looked awkward) with the dot itself pulsing. The indicator now also names *which* failure is the culprit.

## Changed
- **Connection dot is now three states, no halo:**
  - 🟡 **Pulsing yellow** — a live SSH check is in flight (the dot itself pulses; the previous animated "ping" ring is gone).
  - 🟢 **Solid green** — the SSH check connected.
  - 🔴 **Solid red** — the SSH check failed.
- **The amber "Unverified — slow" state is removed.** A timed-out check now reads as red (it genuinely couldn't verify), consistent with "green only if it actually connects." Connectivity is treated as its own signal and is no longer inferred from scan freshness.
- **Failure cause shown as subtext** under a red dot, so you know the culprit at a glance:
  - `Host unreachable` (refused / no route / DNS / reset)
  - `Connection timed out`
  - `SSH key / auth rejected` (auth failure, permission denied, handshake)
  - `SSH host key mismatch`
  - `Connection failed` (fallback)
  The full underlying message remains in the tooltip and the expanded host detail. While checking, the subtext reads "Checking connectivity…".

## Files changed
- `web/src/utils/status.js` (`connectionIndicator` reduced to pending/good/bad + `classifyConnError` cause), `web/src/components/HostCard.jsx`, `web/src/components/HostDetails.jsx`

## Notes for deployment
- Rebuild image (frontend-only). No API/backend changes. The `PATCHDECK_CONNECTIVITY_TIMEOUT_SECONDS` knob (default 15s) from v1.6.0 still applies.

# Patchdeck v1.7.3

Release date: 2026-06-02

## Summary
A small UX fix: host uptime on the dashboard is now **live and reboot-aware** instead of a frozen scan snapshot. **Non-breaking — upgrade in place, no DB or config changes.**

## Changed
- **Live, reboot-aware uptime.** The live connectivity check (which runs every ~30s while the dashboard is open) now also reads `/proc/uptime` in the same SSH round-trip, and the host card shows that value. So uptime refreshes with the connectivity poll rather than staying frozen until the next scan — and because it's read fresh each time, a reboot is reflected correctly: the value drops (e.g. to "just booted") instead of falsely climbing. Falls back to the last scan's uptime when no live reading is available yet.
  - Reading `/proc/uptime` is cheap, locale-proof, and never affects the reachability verdict (uptime is best-effort; a host stays "connected" even if uptime can't be parsed).

## Note on scope
This is a *display* refresh tied to the dashboard's connectivity poll — it updates only **while the dashboard is open** (same as the connectivity dot). It is **not** background fleet monitoring; there is still no server-side liveness/down/reboot alerting (a possible future feature).

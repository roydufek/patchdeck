# v1.8.2

Security-audit housekeeping — clean up the few low-severity advisories surfaced by a full
trivy / grype / govulncheck / npm pass. No functional change.

## Backend
- **`go-chi/chi/v5` 5.1.0 → 5.3.0.** Clears two advisories flagged on 5.1.0:
  `GHSA-vrw8-fxc6-2r93` (host-header injection → open redirect) and `GO-2026-4316`.
  `govulncheck` confirmed neither was reachable in our code (we don't use the affected chi
  paths), so this is supply-chain hygiene rather than an exploitable fix. Build + tests green.

## Frontend
- `npm audit fix` (non-breaking) cleared 4 of 6 build-time advisories (incl. the picomatch
  ReDoS). All are **devDependencies** — they run only during `npm run build` and are NOT in
  the runtime image (which ships only the built static assets). Production deps: 0 advisories.
- The remaining 2 (esbuild dev-server CORS / Deno-install) need a Vite 5→8 major jump that
  breaks the build (`@vitejs/plugin-react@4` is incompatible with Vite 8). They are
  dev-server-only (only matter when running `npm run dev`) and never ship, so the Vite upgrade
  is deferred rather than forced.

## Audit result (v1.8.2)
- **trivy + grype image gates: PASS** (0 fixable HIGH/CRITICAL).
- **govulncheck: no reachable vulnerabilities.**
- Only residual: busybox `CVE-2025-60876` (MEDIUM) in the Alpine base — **unfixed upstream**
  (no patch yet), EPSS < 0.1%, not actionable. The Dockerfile `apk upgrade` pulls the fix
  automatically once Alpine ships it.

No DB or config change.

# Patchdeck v1.1.0

Release date: 2026-06-01

## Summary
Scan/SSH reliability overhaul — the first phase of the reliability refactor. Fixes the class of "scans don't work / return nothing / hang" issues by making remote command execution locale-proof, timeout-bounded, and resilient to transient `apt-get update` failures.

## Fixed
- **Locale-dependent scan parsing.** All remote commands now run under `LANG=C LC_ALL=C`, so `apt list --upgradable` output is stable English and the package parser no longer silently returns zero packages on non-English hosts.
- **`apt-get update` noise polluting results.** stdout and stderr are now captured separately; the package parser reads stdout only. `apt-get update` progress is redirected to stderr (still streamed live to the UI, but never fed to the parser).
- **A failed `apt-get update` no longer zeroes the scan.** Update and listing are decoupled — a transient mirror/network failure is surfaced via a new `apt_update_failed` flag while the package listing still runs against cached metadata.
- **Scans could hang forever.** A configurable per-command execution timeout (`PATCHDECK_EXEC_TIMEOUT_SECONDS`, default 600s) aborts a stuck command (e.g. a host with a held apt/dpkg lock) instead of hanging the operation indefinitely. This is separate from the existing dial timeout.
- **`needrestart` service names** had a leading space and could include blanks; they are now trimmed and filtered.
- **Scheduler safety regression**: `apply` jobs could be scheduled against a host whose `auto_update_policy` is `manual`. Restored the guard that blocks this.
- **Rotted test suite**: `go test ./...` did not compile (`validateBootstrapRole` was referenced but removed). Restored the helper (encoding the "first user must be admin" invariant) so the suite builds and runs; GitHub CI never ran tests, so this had gone unnoticed.

## Added
- `api/internal/sshx/client_test.go` — table-driven tests locking the scan-output parser (packages, phased-update exclusion, reboot/needrestart detection, apt-update-failure, sysinfo extraction) against regressions.
- `PATCHDECK_EXEC_TIMEOUT_SECONDS` config knob.

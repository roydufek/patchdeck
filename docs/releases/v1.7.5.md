# Patchdeck v1.7.5

Release date: 2026-06-03

## Summary
Deferred (phased) updates are now listed in the host **details** panel. **Frontend-only, non-breaking** — no API, DB, or config changes.

## Added
- **Deferred-updates section in host details.** v1.7.4 stopped counting phased updates and showed a small `N deferred (phased)` tag on the host card — but that tag is hidden on mobile (the card drops secondary info on small screens). The host details panel (which *does* render on mobile when you tap a host) now has a dedicated **"N deferred (phased)"** section listing each held-back package (name + version), with a short explanation: *"Upgradable, but held back for now — Ubuntu rolls these out gradually; they'll install automatically once the rollout reaches this host."* So the deferred set is visible everywhere, not just the desktop card.

## Files changed
- `web/src/components/HostDetails.jsx`
- `api/internal/config/config.go` (version bump)

# v1.8.15

Adds **OpenID Connect (OIDC) single sign-on** as an optional login method, alongside the
existing local password + TOTP (which stays as a break-glass login).

## Added

- **OIDC login (Authorization Code + PKCE).** Configure an issuer, client ID, and client
  secret in Settings → *Single sign-on (OIDC)*, and a "Sign in with SSO" button appears on
  the login page. Verified against Pocket ID; works with any standard OIDC provider
  (Authentik, Authelia, Keycloak, Zitadel, …).
- **The IdP is the gate.** Patchdeck is single-admin, so an SSO login is authenticated by
  the provider and then granted the existing admin session — there is no per-user account
  to reconcile. Restrict *who* can use the client in your IdP (recommended), or set an
  optional comma-separated **allowlist** of emails/groups in Patchdeck as a second gate.
- **Settings scaffolding:** issuer/provider URL, client ID, write-only client secret
  (AES-GCM encrypted at rest via the master key), optional public base URL, optional button
  label, optional allowlist, and a **read-only callback URL** to copy into the provider.
- **Break-glass preserved:** local username/password + TOTP still work, so a down IdP can't
  lock you out of the tool you'd use to fix it.

## Security

- **Standard hardening on the flow:** anti-CSRF `state`, replay `nonce`, and PKCE (S256),
  all carried in short-lived, path-scoped (`/auth/oidc`), httpOnly, `Secure`, `SameSite=Lax`
  cookies that are cleared as soon as the callback resolves. State and nonce are compared in
  constant time. The ID token is verified (JWKS signature, issuer, audience `client_id`,
  expiry) via `coreos/go-oidc`.
- **Client secret** is stored only as AES-GCM ciphertext (`internal/crypto` SealBox), never
  returned to the frontend (`has_client_secret` boolean only) and never logged.
- **Fixed redirect path** (`/auth/oidc/callback`), success redirect is always the app root —
  no request-controlled redirect target (no open-redirect surface).
- **New deps:** `github.com/coreos/go-oidc/v3` + `golang.org/x/oauth2` (+ their transitive
  `go-jose`). Both scanner gates + govulncheck clean.

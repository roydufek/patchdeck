# Patchdeck v1.4.0

Release date: 2026-06-01

## Summary
Frontend data-layer overhaul to eliminate the status-color flicker and other "oddball" refresh glitches. The dashboard's hand-rolled state hook (which wrote host connectivity from four racing async paths) is replaced internally by [TanStack Query](https://tanstack.com/query), giving a single source of truth per resource, cached reads that keep showing last-good data during refetch (no flip-to-empty), and request deduplication. Component code is unchanged — `useHosts` keeps the same return shape.

## Fixed
- **Status colors flickering / hosts flashing Connected↔Disconnected↔Checking.** Connectivity is now a single cached query rather than a `useState` map mutated from four places (full reload, per-host check, optimistic action updates, stream completion). Those paths now all update one cache entry, so there is no longer a race that flips the indicator on every render.
- **Live SSH connectivity checks no longer run on every dashboard refresh.** They previously fired on each load, so a transient blip would flip a host red then green. Connectivity now refreshes on mount, after an action, and on demand — host health is otherwise derived from the stable last-scan snapshot.
- **Flip-to-empty on refresh.** `keepPreviousData` means the host/scan lists keep rendering the last good data while a background refetch is in flight, instead of briefly clearing.

## Added
- `@tanstack/react-query` (+ `QueryClientProvider` in `main.jsx`). Query defaults: no refetch-on-focus, 10s stale time, hosts/scans poll every 30s with `keepPreviousData`.

## Files changed
- `web/src/hooks/useHosts.js` (internals rewritten; public return shape unchanged)
- `web/src/main.jsx`, `web/package.json`, `web/package-lock.json`

## Notes for deployment
- Rebuild image (the build now installs `@tanstack/react-query`). No backend or API changes.
